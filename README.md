ا                                                                                                 التلاتة  بنستخدمهم لتعريف أنواع بيانات مخصصة 
class بنستخدمها لإنشاء كائنات (Objects) تجمع البيانات والوظائف المتعلقة بها.
struct شبه الـ class في كتابة البيانات والـ Methods، لكن الفرق الأساسي إنها Value Type.
record نوع بيانات مناسب عندما تكون قيمة البيانات نفسها أهم من هوية الكائن.
record يقارن البيانات المكونة له، وليس مجرد هوية الكائن.
Indexer هو ميزة بتسمح لك تتعامل مع Object باستخدام الأقواس المربعة []، بطريقة تشبه الوصول إلى عناصر الـ Array.
